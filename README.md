# Daily Diet Log

くみこ専用・1日のダイエット記録サイト。入力するとスプレッドシートへ自動追記されます。

## 構成
- `index.html` … 入力サイト（GitHub Pagesで公開）
- `Code.gs` … スプレッドシート側に貼るコード（自動追記）

## 保存先のつなぎ方（初回のみ・約2分）
1. 記録したいスプレッドシートを開く
2. 上メニュー **拡張機能 → Apps Script**
3. `Code.gs` の中身を **全部貼り付け**て保存
4. 右上 **デプロイ → 新しいデプロイ → 種類「ウェブアプリ」**
5. **次のユーザーとして実行：自分／アクセス：全員** を選ぶ
6. **デプロイ** → 一度だけ承認（自分のGoogleを許可）
7. 表示された **ウェブアプリのURL（.../exec）** をコピー
8. 入力サイトの **⚙設定** に貼って「保存する」→「つながるかテスト」でOKが出れば完了

## 仕組み
- 「保存」→ サイトがJSONをGASにPOST → GASが既存の下に「1日ブロック」を追記
- 合計 / 差分 / 前日比 / 累計 は自動計算
- 前日の数値・当初(Day0)の数値は、シートの過去ブロックから自動で拾います
- BMIは体重から自動計算（身長は設定で変更・初期164cm）

## あいことば（token）
サイトの token と `Code.gs` の `TOKEN` は同じ文字にすること（初期値 `merone-diet-2026`）。
